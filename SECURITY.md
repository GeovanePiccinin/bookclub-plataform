# Política de Segurança

## Versões suportadas

| Versão | Suporte a correções |
| ------ | ------------------- |
| `main` | Sim                 |

O Book Club Platform é uma base de código, não um serviço hospedado. Mantenha
suas dependências e deploys atualizados de forma independente.

## Reportar uma vulnerabilidade

Não publique vulnerabilidades, credenciais, dados pessoais ou passos de
exploração em Issues públicas.

Se o repositório habilitar Private Vulnerability Reporting, use a opção
**Security → Advisories → Report a vulnerability** no GitHub. Caso não esteja
disponível, contate os mantenedores por um canal privado listado no perfil do
repositório. Não presuma que o recurso de reporte privado esteja habilitado.

Inclua impacto, versões/commit afetados e evidências mínimas sanitizadas. Os
mantenedores buscarão confirmar o recebimento e coordenar correção e divulgação
responsável. Não há prazo de resposta garantido.
